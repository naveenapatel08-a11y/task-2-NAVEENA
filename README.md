# Data Classification Using AI

## Description
A machine learning project that classifies data into different categories using AI techniques. The model is trained on a dataset to predict and categorize new data accurately.

## Features
- Data preprocessing
- AI-based classification
- Model training and prediction
- Performance evaluation
- User-friendly implementation

## Technologies Used
- Python
- Machine Learning
- Pandas
- NumPy
- Scikit-learn

## How to Run
1. Clone or download the repository.
2. Install the required libraries.
3. Run the Python file:

python data_classification.py
